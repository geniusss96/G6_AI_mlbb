# Claude Tactical AI Brain — Автономный ИИ-ассистент для MLBB (Mobile Legends)

Комплексная интеллектуальная система управления героем **Клод (Claude)** в реальном времени. Система объединяет нейросетевое компьютерное зрение (YOLOv8), оптический анализ состояний (OpenCV HSV), обучение с подкреплением (Q-Learning), адаптивный джойстик и низколатентный контроллер ADB-макросов.

## 2. Хронология проблем и инженерные решения (От начала до конца)

Ниже зафиксированы 7 критических проблем, которые привели проект в тупик, и архитектурные решения, полностью восстановившие работоспособность бота.

### Проблема 1: Паралич персонажа при автоатаке (Конфликт мультитача Android)
* **Причина:** Встроенная утилита Android `/system/bin/input` не поддерживает независимый мультитач для разных процессов. Когда джойстик отправлял `input motionevent DOWN` и переходил в режим непрерывного ведения `MOVE` (`is_holding = True`), параллельный выстрел автоатаки `input swipe` создавал на экране свой `ACTION_DOWN` и в конце — `ACTION_UP`. Этот `ACTION_UP` сбрасывал нажатие джойстика на уровне ядра Android. Джойстик продолжал слать `MOVE`, но без активного `DOWN` операционная система игнорировала движение. Клод застывал на месте намертво.
* **Решение:** 
  1. В `JoystickController` добавлен метод `notify_screen_touched()`, сбрасывающий флаг `is_holding = False`.
  2. При каждом вызове автоатаки или касте способностей в `claude_macro` джойстик мгновенно уведомляется и на следующем кадре выполняет новый `motionevent DOWN`.
  3. В `move_towards` и `kite_away` добавлен сторожевой таймер: если контакт длится дольше 1.8 с, стик плавно обновляет `DOWN`, гарантируя 100% непрерывный бег.

### Проблема 2: Сжатие окна Scrcpy и сдвиг координат (1270x592 vs 1544x720)
* **Причина:** Разрешение монитора ПК — `1366x768`. Телефон имеет физическое разрешение `1544x720`. Окно Scrcpy автоматически уменьшалось оконным менеджером Windows до `1270x592`. Детектор готовности скиллов `SkillStateChecker` проверял фиксированные пиксели `(1088, 540)`, которые на сжатом кадре указывали в пустую область интерфейса. Расстояния боя (кайтинг 280px, свит-спот 430px) также искажались на ~18%.
* **Решение:** Сразу после захвата области окна через `sct.grab(monitor)` кадр нормализуется:
  ```python
  if frame.shape[1] != 1544 or frame.shape[0] != 720:
      frame = cv2.resize(frame, (1544, 720), interpolation=cv2.INTER_LINEAR)
  ```
  Все последующие алгоритмы (YOLO, детекторы цвета, дистанции, HUD) работают в единой эталонной системе координат 1:1 со смартфоном.

### Проблема 3: Процессорный оверхед от запуска `adb.exe`
* **Причина:** Каждые 0.2 секунды функция `fire_basic_attack_fast()` вызывала `subprocess.Popen([adb.exe, ...])`. Запуск нового процесса Windows `adb.exe` занимает 80–120 мс, создавал нагрузку на CPU и лаги отклика.
* **Решение:** В `claude_macro` внедрен метод `_send_fast_cmd()`, который направляет команды тапа напрямую в **уже открытый интерактивный ADB Shell джойстика**. Задержка выполнения команды сократилась с 100 мс до **<0.1 мс**.

### Проблема 4: Зависание комбо на 2.8 секунды и механика Клода
* **Причина:** В комбо `trigger_engage_ultimate` присутствовал 5-й шаг (повторный свап S2), однако механика Клода в игре допускает только один телепорт с Декстером. Каст блокировал мьютекс `_lock` на 2.8 секунды, игнорируя ручные нажатия пользователя.
* **Решение:** Комбо оптимизировано под динамику MLBB:
  1. `S2 (Декстер)` -> пауза 120 мс
  2. `S2 (Телепорт в гущу)` -> пауза 50 мс
  3. `S1 (Кража скорости)` -> пауза 40 мс
  4. `Ultimate (Взрывной урон)` -> удержание 1.0 с
  Общее время прокаста снижено с 2736 мс до **1210 мс**.

### Проблема 5: «Депрессивная спираль» Q-обучения (`q_brain.json`)
* **Причина:** Таймер бездействия `IDLE_PENALTY_INTERVAL` был установлен всего в 8.0 секунд с жестким штрафом `-15.0`. Обычный переход Клода от фонтана до внешних вышек занимает 12–15 секунд. В результате бот каждую прогулку до линии воспринимал как ошибку и за несколько минут загнал все действия разведки `SCOUT_DEEP_PATROL` в глубокий минус (`LANE_ADVANCE: -18.31`). ИИ перестал предпринимать активные действия.
* **Решение:**
  1. `IDLE_PENALTY_INTERVAL` увеличен до **25.0 секунд**.
  2. Штраф за смену сектора смягчен с `-15.0` до `-3.0`.
  3. В `q_brain.json` отрицательные веса сброшены на здоровые базовые значения (`+15..+30`).

### Проблема 6: Ложные убийства и стрельба по трупу Зилонга
* **Причина:** Бот засчитывал убийство героя, если враг просто уходил в кусты или за край экрана на 1.8 с. Когда же враг реально погибал, красный плащ на земле определялся оптическим фильтром как живая цель. Через 3.5 секунды срабатывал сторожевой таймер, который накладывал на бота штраф `penalize_wall_stuck`.
* **Решение:**
  1. Убийство засчитывается только если длительность реального огневого контакта превышала 2.0 секунды.
  2. Если объект неподвижен более 2.5 с, он сразу вносится в черный список трупов на 20 секунд без вызова штрафа стены.

### Проблема 7: Потеря свёрнутого окна Scrcpy
* **Причина:** При свёртывании Scrcpy функция `GetWindowRect` возвращает координаты `(-32000, -32000)`, из-за чего бот терял окно и бесконечно спамил об ошибке в консоль.
* **Решение:** В `find_scrcpy_window` добавлено авто-восстановление окна:
  ```python
  if rect[0] < -1000 or rect[1] < -1000:
      win32gui.ShowWindow(hwnd, win32con.SW_RESTORE)
  ```

## 3. Описание ключевых файлов проекта

| Файл | Назначение |
|---|---|
| `realtime_vision.py` | **Главный цикл бота.** Захват экрана, инференс YOLOv8, оптические сенсоры, принятие тактических решений, отрисовка боевого HUD. |
| `joystick_controller.py` | **Контроллер виртуального стика.** Реализует непрерывный бег, кайтинг назад, орбитальный стрейф (орб-вокинг) через `input motionevent`. |
| `claude_macro.py` | **Макросы и комбо Клода.** Быстрые выстрелы, прокаст фулл-комбо, панический отскок (S2 назад), автопрокачка навыков и автозакуп. |
| `claude_brain.py` | **Мозг с Q-Learning.** Содержит таблицы Q-весов для разведки, фарма и дуэлей, рассчитывает настроение ИИ и сохраняет «Золотой фонд» моментов. |
| `q_brain.json` | **Файл долгосрочной памяти ИИ.** Сохраняет накопленный опыт между запусками игры. |
| `runs/detect/.../best.pt` | **Обученная нейросеть YOLOv8.** Веса для детекции вражеских/союзных героев, полосок HP, крипов, вышек и баффов. |

## 4. Быстрый запуск

### Требования
- Python 3.10+
- Подключенный Android-смартфон с включенной **Отладкой по USB** (Серийный номер: `R3CT90BBMTX`).
- Утилита `scrcpy` (входит в поставку или установлена в системе).

### Шаги запуска:
1. Запустите окно трансляции смартфона через Scrcpy:
   ```powershell
   cd C:\Users\user\Desktop\scrcpy-win64-v4.1
   .\scrcpy.exe
   ```
2. Откройте Mobile Legends и зайдите в матч (или тренировочный режим с ботом Зилонгом).
3. В отдельном окне терминала запустите тактический мозг:
   ```powershell
   cd "C:\Users\user\Desktop\скрипт(mlbb)"
   python realtime_vision.py
   ```

### Управление и горячие клавиши:
* **[Space]** или **[F]** — Принудительный ручной запуск взрывного комбо (S2 -> S2 -> S1 -> Ult).
* **[Q]** или **[Esc]** — Безопасное завершение работы бота с автоматическим сохранением опыта в `q_brain.json` и отпусканием джойстика.
