# Данные и обучение YOLO

В проекте два разных вида обучения: YOLO учится распознавать объекты на размеченных
изображениях, а тактический мозг получает опыт из игровых действий и наград.
Обучение YOLO само по себе не научит агента выигрывать матчи.

## Что показал аудит

Проверены файлы ветки `codex/fix-runtime-capture-errors`. Полный список проблем,
число рамок каждого класса и предупреждения путей — в `docs/dataset_audit.json`.
Это проверка структуры и геометрии разметки, а не экспертная проверка каждого объекта.

| Датасет | Классов | Train / val / test | Проблемных примеров |
| --- | ---: | --- | ---: |
| MLBB_Claude_Bot.v2i.yolov8 | 14 | 161 / 20 / 23 | 0 |
| MLBB_Combined_v4 | 14 | 656 / 121 / 100 | 209 |
| MLBB_Datos_v1 | 103 | 314 / 90 / 45 | 312 |
| MLBB_New_Dataset | 13 | 343 / 33 / 55 | 1 |

Нельзя просто объединять txt-файлы: номер класса обозначает разные объекты в разных
наборах. Например, в Combined_v4 класс 0 — hp_self, а в первом наборе — hero.
У New_Dataset есть неоднозначное имя `12`; автоматически угадывать его смысл нельзя.
У Datos_v1 отдельная схема на 103 класса. В этой версии используется Combined_v4;
нового объединения источников и изменения ID классов нет.

В Combined_v4 найдено 209 примеров с рамками, выходящими за изображение.
Консервативная подготовка исключает весь такой пример, чтобы не оставить объект
без части его аннотаций. Она не исправляет рамки автоматически. Исходные файлы
остаются на месте для последующей ручной проверки.

В подготовленной копии остаются 668 изображений: train 506, val 79, test 83.
Совпадающих декодированных изображений в этом наборе не найдено. Проверка не
обнаруживает почти одинаковые соседние кадры видео, поэтому независимость сцен
в проверочной выборке ещё нужно оценить вручную.

## Запуск в PowerShell из папки проекта

Используй то же Python-окружение, где у тебя уже работает CUDA. Для новых инструментов:

```powershell
python -m pip install PyYAML Pillow
python -m unittest tests.test_dataset_tools
python -m training.dataset_tools audit --report data/dataset_audit_local.json
python -m training.dataset_tools prepare
python -m training.train_v4 --dry-run
```

`audit` возвращает код 2, если нашёл проблемы или повторы. Это результат проверки,
а не падение. Подробности сохраняются через `--report`.

`prepare` создаёт `datasets/prepared/v4_clean`, собственный `data.yaml`, отчёт и
manifest с хэшами изображений. Она проверяет ID, число полей, конечность чисел,
размер рамок, читаемость изображений и наличие txt-разметки. Пустой txt допускается
как явно размеченный фон; отсутствующий txt исключает пример.

Повторы определяются по декодированным RGB-пикселям. Сохраняется один экземпляр,
приоритет test → val → train: проверочные изображения не переносятся в обучение.
Если у одинакового изображения разная разметка, исключается вся группа. Это
строгое правило; оно не сравнивает разметку с допуском по координатам.

Если папка уже существует, инструмент откажется её перезаписывать. Для новой версии:

```powershell
python -m training.dataset_tools prepare --output datasets/prepared/v4_clean_2
python -m training.train_v4 --data datasets/prepared/v4_clean_2/data.yaml --dry-run
```

После успешного `--dry-run` можно запускать настоящее обучение:

```powershell
python -m training.train_v4 --device 0 --batch 4 --epochs 50
```

Batch 4 — начальный параметр для видеокарты с 6 ГБ памяти, а не гарантия, что памяти
хватит в любом окружении. При CUDA out of memory попробуй `--batch 2`.
`--device auto` выберет CUDA, если её видит PyTorch, иначе CPU.

Скрипт использует YOLOv8n; при отсутствии `yolov8n.pt` Ultralytics может скачать
стартовые веса. Результат сохраняется в отдельный каталог `runs/detect`.
Рабочий `models/yolo/v4/best.pt` автоматически не заменяется.

Перед подключением новых весов нужны проверка метрик по классам и наблюдение на
записи игры. В очищенном train есть всего 1 рамка money, 3 vazon и 7 tron_self:
для уверенного распознавания этих классов данных мало. Маленькие классы следует
дособрать, а не считать готовыми по одной общей метрике.

В этой среде подготовка и dry-run проверены. Настоящая тренировка, CUDA на твоём
ПК, распознавание новых весов и управление телефоном здесь не проверены.
